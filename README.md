## Configuration:
>*Note: This project was developed using a combination of GitHub Desktop and VS Code.*
1. Download the source code (/src for main application, /lib for JUNIT dependcy)
2. Navigate to this downloaded directory --> cd *FOLDER_PATH*
3. Compile the source code into bytecode --> javac *.java
4. Run the main program                  --> java Main

>*Note: This project assumes you have the JVM installed and JDK tools. If you do not, the relevant downloads are [here](https://www.oracle.com/java/technologies/downloads/)*

## Project Runtime:
There are 3 key UX scenarios that allow you to interact with our system:
1. Alien = escape the planet
2. Scientist = land a research plane
3. Soldier = prevent a containment breach

Standard human I/O interaction is done through the terminal, in which you will be prompted to enter an integer choice most of the time.
Type EXIT to leave the program gracefully at any time.
